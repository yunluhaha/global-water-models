# 16 Global Water Models | 16种全球水模型

> An interactive bilingual (EN/中文) webpage for intercomparison of 16 state-of-the-art global water models.  
> 基于跨部门影响模型比较项目（ISIMIP）的16种全球水模型交互式双语网页。

🌐 **Live Site | 在线访问**: [https://yunluhaha.github.io/global-water-models/](https://yunluhaha.github.io/global-water-models/)

---

## Overview | 概述

This webpage provides an interactive overview of the **16 global water models** documented in Telteu et al. (2021), covering three model categories:

本网页基于 Telteu et al. (2021) 整理了16种全球水模型，涵盖三类模型：

| Category | 类型 | Count | Models |
|----------|------|-------|--------|
| Land Surface Models (LSM) | 陆面模型 | 6 | CLM4.5, CLM5.0, DBH, JULES-W1, MATSIRO, ORCHIDEE |
| Global Hydrological Models (GHM) | 全球水文模型 | 9 | CWatM, H08, Mac-PDM.20, mHM, MPI-HM, PCR-GLOBWB, VIC, WaterGAP2, WAYS |
| Dynamic Global Vegetation Models (DGVM) | 动态全球植被模型 | 1 | LPJmL |

---

## Features | 功能

- 🌐 **Bilingual toggle** — Switch between English and Chinese at any time  
  **中英切换** — 随时切换语言，卡片、表格、参考文献全部联动
- 🃏 **Model cards** — Visual cards for each model with key attributes  
  **模型卡片** — 每个模型的可视化展示，含开发机构、分辨率、特性标签
- 🔍 **Filter & search** — Filter by model type (LSM / GHM / DGVM) or irrigation representation  
  **筛选与搜索** — 按类型或灌溉属性筛选，实时搜索
- 📊 **Comparison table** — Side-by-side attribute comparison (10 columns)  
  **对比表格** — 10列属性并排对比，联动筛选
- 📚 **References** — 17 full bilingual references with DOI links  
  **参考文献** — 17条完整中英文参考文献，附 DOI 超链接
